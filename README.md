## Blue Archive Halos - Pyroxene
This mod brings the students' halos from Blue Archive into Minecraft by trading Netherite Helmet from Armorer Villager.

The halos have been modeled and animated to closely match their original appearance in Blue Archive.

## Features
- Just like the [original mod](https://www.curseforge.com/minecraft/mc-mods/blue-archive-halos).
- Supports the latest Minecraft versions.
- Halos now appear in the Creative Inventory.
- **Smooth halo movement physics** inspired by Blue Archive Short Animation (disabled by default).
- And several other fixes.

## Dependencies
**Geckolib** is required. For Fabric, the **Fabric API** is also required.

For Fabric, the following dependencies are optional:
- Forge Config API Port (configuration support).
- ModMenu (accessing config GUI).
